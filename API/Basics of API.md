# What is API :

APIs are mechanisms that enable two software components such as frontend and backend to communicate with each other using a defined set of __rules , protocols and data formats__ 

Ex . customer waiter and kitchen where waiter is the API who connects the customer and the kitchen 

Before APIs __monolithic architecture__ was followed where backend and frontend are tightly coupled and both depend a lot on each other and are packed in a single folder .
