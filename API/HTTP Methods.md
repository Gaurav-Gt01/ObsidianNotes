Types of Softwares/Websites :
- Static : Only one way interaction , ex. Calendar , blog websites.
- Dynamic : Two way communication . ex Excel , youtube , instagram .

Types of Interactions : CRUD (create , retrieve , update , dynamic)

There is client server interactions , that is done using http protocols . 

HTTP Methods :
- Post - for create action .   C
- Get - for retrieval action .  R
- Put - for update action .    U
- Delete - for delete action .D
